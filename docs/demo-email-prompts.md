# ParaWorks 데모 이메일 생성 프롬프트

이 문서의 프롬프트를 ChatGPT, Claude 등 LLM에 붙여넣어 각 Gmail 스레드 내용을 생성한다.
생성된 내용을 실제 Gmail 계정 간에 수동으로 발송한다.

---

## 공통 컨텍스트 프롬프트

> **사용법**: 각 Thread 프롬프트를 사용하기 전에 반드시 이 컨텍스트를 먼저 붙여넣거나,
> 같은 대화 세션에서 이어서 사용한다.

```
당신은 한국 스타트업 "ParaWorks Inc."의 팀원 역할을 맡아 실제 업무 이메일을 작성합니다.

현재 초기 제품을 완성하고, 첫 엔터프라이즈 파일럿 고객 유치와 
시드 투자 유치를 병행하고 있습니다.

## 이메일 작성 원칙
1. 한국 스타트업 문화에 맞는 격식체와 친근함의 중간 톤 (ex. "~합니다", "~드립니다")
2. 불필요한 형식적 인사말은 최소화 (짧고 실무적으로)
3. 각 메일은 150~300자 내외로 간결하게
4. 실제 업무 상황처럼 구체적인 수치와 날짜를 포함
5. 각 메시지 끝에 다음 행동(Action Item) 또는 결정사항이 명확히 드러나야 함
6. 회신 시 이전 메시지 내용을 자연스럽게 이어받아 작성
```

## 사용 가이드

### 순서

1. **공통 컨텍스트 프롬프트** 를 LLM 대화창에 먼저 입력
2. 원하는 **Thread 프롬프트**를 이어서 입력
3. 생성된 각 메일 내용을 아래 발송 순서대로 실제 Gmail에서 수동 발송

### 발송 순서 및 계정

### CC/참조 설정 주의

- Thread 1, 3: `mina@paraworks.com` CC에 포함
- Thread 4: `hanvv3@koreacu.ac.kr` CC에 포함

### Gmail 발송 팁

- **같은 스레드**를 유지하려면 반드시 **"Reply" (회신)** 기능 사용 (새 메일 금지)
- 발송 전 제목이 `Re: [원본 제목]` 형태로 유지되는지 확인
- 첨부파일이 있는 경우 (Thread 2, 5) 해당 Drive 파일을 로컬에서 첨부
