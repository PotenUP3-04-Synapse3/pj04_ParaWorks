# 프로젝트 중심 지식 자동화 및 AI 비서 활용 가이드 (Alembic 협업 가이드 포함)

이 문서는 ParaWorks의 파편화된 데이터(Slack, Email, Drive)를 **'프로젝트'**라는 기준 아래 자동으로 묶고, 이를 타임라인과 AI 비서에서 어떻게 활용할지에 대한 통합 계획서입니다. 또한, DB 구조 변경 시 팀원들이 어떻게 동기화해야 하는지에 대한 가이드를 포함합니다.

---

## 1. 프로젝트 목적 (Objective)
현재 ParaWorks는 데이터를 수집하고 분석하는 능력은 갖추었으나, 이를 **어느 프로젝트의 내용인지** 자동으로 분류하고 연결하는 고리가 약합니다. 본 계획은 데이터를 승인하는 즉시 해당 프로젝트의 타임라인에 나타나게 하고, AI 비서가 프로젝트 단위의 질문에 똑똑하게 답하게 만드는 것을 목표로 합니다.

---

## 2. 핵심 작업 계획 (Implementation Plan)

### Phase 1: 데이터 그릇 준비 (DB 스키마 보강)
*   **작업**: 결정사항(Decision), 할 일(Todo), 히스토리(History) 등 모든 지식 데이터에 `project_key`(프로젝트 고유 키) 컬럼을 추가합니다.
*   **Alembic 활용**: 컬럼 추가 시 Alembic 마이그레이션 스크립트를 생성하여 팀원들이 수동으로 DB를 건드리지 않고도 명령어로 동기화할 수 있게 합니다.

### Phase 2: AI 자동 분류 및 사용자 검토 UI
*   **자동 분류**: 슬랙 메시지가 들어오면 AI가 `topic_tag`를 분석해 기존 프로젝트 리스트 중 가장 어울리는 곳을 자동 추천합니다.
*   **수동 수정**: 검토(Review) 페이지에서 관리자가 AI의 추천이 틀렸을 경우 드롭다운 메뉴로 프로젝트를 직접 변경할 수 있게 합니다.

### Phase 3: 승인 및 승격(Promotion) 파이프라인 완성
*   **작업**: '승인' 버튼을 누르면 `ReviewItem`에 담긴 프로젝트 정보가 실제 타임라인 테이블로 그대로 복사되도록 로직을 일원화합니다.
*   **결과**: 승인과 동시에 타임라인 탭의 해당 프로젝트 섹션에 즉시 노출됩니다.

---

## 3. [협업 필수] DB 변경 사항 적용 방법 (Alembic)

지식 데이터에 `project_key` 컬럼이 추가되면, 다른 팀원(AI 비서 담당자 등)은 자신의 로컬 환경에서 다음 명령어를 실행하여 DB 구조를 최신화해야 합니다.

1.  **최신 코드 내려받기**: `git pull`
2.  **DB 스키마 업데이트**: 터미널(가상환경 활성화 상태)에서 아래 명령어 실행
    ```powershell
    uv run alembic upgrade head
    ```
    *   **설명**: 이 명령어를 실행하면 제가 만든 '컬럼 추가 레시피'가 팀원의 DB에 자동으로 적용되어, 새로 추가된 `project_key` 필드를 사용할 수 있게 됩니다.

## 4. AI 비서 담당자를 위한 활용 가이드 (For AI Developer)

> **RAG 관점의 핵심**: 이제 모든 검색 결과(Search Result)에는 `project_key`와 `project_name`이 포함됩니다. 이를 활용해 다음과 같은 기능을 구현하세요.

### A. 프로젝트 가중치 검색 (Project-Weighted Search)
사용자가 "우리 **'RAG 고도화'** 프로젝트 어떻게 돼가?"라고 물으면, 질문 속의 프로젝트 키워드를 추출하여 해당 `project_key`를 가진 데이터에 더 높은 우선순위(Weight)를 주어 검색하세요.

### B. 타임라인 요약 답변 (Timeline Summarization)
"A 프로젝트의 결정사항만 요약해줘"라는 질문을 받으면, 일반 슬랙 메시지가 아닌 승인된 `DecisionRecord`와 `TimelineEvent` 테이블의 데이터를 우선적으로 참고하세요.

### C. 근거 UI 개선 (Enhanced Citations)
AI 답변 하단의 근거 표시 영역에 프로젝트 명을 함께 노출하여 사용자에게 맥락을 제공하세요.
*   **추천 포맷**: `[근거: 💬슬랙 #채널명, 작성자, 🚀프로젝트명]`

---

## 5. 데이터 흐름 요약 (Data Flow)

1.  **수집**: 슬랙/메일/드라이브 데이터 유입
2.  **분석**: AI가 주제 파악 및 **프로젝트 자동 매핑**
3.  **검토**: 사람이 프로젝트 소속 확인 및 **승인(Approve)**
4.  **반영**: 타임라인 및 프로젝트 탭에 **즉시 노출**
5.  **답변**: AI 비서가 **프로젝트 맥락**을 포함하여 답변
