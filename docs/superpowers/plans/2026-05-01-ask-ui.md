# Ask UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Expose the RAG Orchestrator `/api/v1/ask` endpoint in the frontend so Korean business users can ask ParaWorks company memory questions with citations and cost metadata.

**Architecture:** Extend the existing `/search` page into a combined Ask + Evidence workbench. One query input drives both `/api/v1/ask` and `/api/v1/search` using viewer permissions, so users can see the generated answer, source evidence, permission notice, token usage, and estimated cost in one place.

**Tech Stack:** Next.js 15, React 19, TypeScript, Tailwind, existing FastAPI `/api/v1/ask` and `/api/v1/search` endpoints.
