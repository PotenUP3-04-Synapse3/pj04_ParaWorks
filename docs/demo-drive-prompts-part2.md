## 사용 순서 가이드

1. `demo-drive-prompts-part1.md` 상단의 **공통 컨텍스트** → LLM에 먼저 입력
2. 원하는 프롬프트를 이어서 입력 → 내용 생성
3. 생성된 내용을 아래 형식으로 저장:
   - `.md` 파일 → 텍스트 에디터에서 저장 후 Drive 업로드
   - `.docx` 파일 → Word/Google Docs에 붙여넣기 후 저장
   - `.pdf` 파일 (IR 데크) → Google Slides에서 작성 후 PDF 내보내기

## 파일별 권한 설정 (Drive 업로드 후)

Drive 자체 공유 설정이 아닌, ParaWorks 연동 후 시스템 내 `permission_level`은
데이터베이스에서 직접 설정하거나 향후 UI에서 관리.

| 파일 | permission_level |
|:---|:---|
| `03_IR_투자/` 전체 | restricted |
| `02_파일럿_프로젝트/K테크_NDA_초안.docx` | restricted |
| 나머지 전체 | internal |
