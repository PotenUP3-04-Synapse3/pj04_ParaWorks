# K테크 솔루션즈 온보딩 체크리스트

K테크 솔루션즈의 원활한 ParaWorks 도입을 위한 단계별 온보딩 항목입니다.

## 1. 온보딩 전 준비 (ParaWorks 측)
- [ ] **화이트리스트 등록**: K테크 측의 메일 도메인(`@k-tech.co.kr`) 및 IP 대역을 접근 허용 목록에 추가.
- [ ] **계정 생성**:
  - 관리자 계정 (2명): k-admin1, k-admin2
  - 일반 사용자 계정 (18명): 전략기획팀 및 유관 부서원
- [ ] **NDA 체결 확인**: 법인 간 비밀유지계약서 최종 서명 여부 확인.

## 2. Day 1 체크리스트 (K테크 담당자 수행)
- [ ] **Google OAuth 연동**: Google Workspace 관리자 계정으로 ParaWorks와 드라이브/메일 연동 승인.
- [ ] **Slack 봇 설치**: K테크 Slack 워크스페이스에 ParaWorks Agent 앱 설치 및 채널 초대.
- [ ] **첫 동기화 실행**: `POST /api/v1/integrations/sync` 호출을 통해 초기 데이터 인덱싱 시작.
- [ ] **결과 확인**: `/documents` 페이지에서 문서들이 정상적으로 리스팅되는지 확인.

## 3. Week 1 체크리스트
- [ ] **데이터 샘플링 확인**: 주요 채널의 메시지가 정확히 동기화되고 있는지 한준혁님이 기술 검토.
- [ ] **Review Queue 첫 승인**: 김미나님이 K테크 담당자에게 AI 추출 후보를 승인/반려하는 방법을 시연하고 첫 사례 생성.
- [ ] **사용자 가이드 배포**: 사내 공지 채널을 통해 간단한 사용법 가이드 전달.

## 4. 성공 확인 기준
- 관리자가 첫 번째 결정사항을 승인하여 Knowledge Base에 등록 완료.
- 사용자 질문에 대해 AI가 K테크 내부 문서를 인용(Citation)하여 답변 성공.
