## 2. 주요 질의응답 (Q&A)

**Q1. 팀 구성에서 엔지니어 비중이 낮아 보이는데, 기술적 해자가 충분한가?**
- **A**: 현재 CTO 김용희님이 핵심 아키텍처를 리딩하고 있으며, 이번 투자금으로 시니어 엔지니어 2명을 즉시 채용할 계획임. LangGraph 기반의 독자적인 에이전트 워크플로우가 우리의 핵심 자산임.

**Q2. K테크 외에 파일럿을 논의 중인 다른 고객사가 있는가?**
- **A**: 현재 IT 서비스 기업 2곳, 제조 기반 스타트업 1곳과 제안서를 주고받는 단계임. 1월 중 추가 파일럿 1개 이상을 더 확정할 예정임.

**Q3. 대량의 데이터 인덱싱 시 API 비용 및 서버 부하 문제는 어떻게 해결하나?**
- **A**: Content-hash 기반의 중복 제거와 증분 동기화 기술을 적용하여 불필요한 LLM 호출을 70% 이상 절감함.
